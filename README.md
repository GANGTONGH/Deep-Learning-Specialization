# Deep Learning Specialization

## Disclaimer
**These code implementations are intended for reference purposes only.**
Please make a sincere effort to complete the assignments on your own before consulting this repository. **Do not copy or submit these codes as your own work.**

This repository contains programming assignments from the [Deep Learning Specialization](https://www.deeplearning.ai/courses/deep-learning-specialization/) by DeepLearning.AI. I understand that applying new deep learning concepts using unfamiliar tools (e.g., TensorFlow, PyTorch) can be challenging at first. The code here is shared to offer guidance or hints to those who may be stuck, and to support the learning process — **not as a substitute for independent work**.
